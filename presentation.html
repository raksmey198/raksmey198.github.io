How it works

Setup steps

  1. Created a GitHub account (username: raksmey198)
  2. Installed Git and the GitHub CLI: winget install
  3. Signed in from the computer: gh auth login, then authorized in the browser
  4. Created the repository and pushed the site
  5. Turned on GitHub Pages to get a live link
